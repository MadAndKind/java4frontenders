## Zadania / Materiały

Błąd z var vs typy: Pokazuje, że var w Javie to tylko ukrycie typu przez kompilator (tzw. type inference), a nie dynamiczny typ z JS.

Pułapka == vs .equals(): To klasyczny "killer" dla każdego programisty JS przechodzącego na Javę (w JS === porównuje wartość, w Javie dla obiektów == sprawdza, czy to ten sam adres w pamięci).

Konstruktor z this: Pokazuje zbliżoną składnię do klas z ES6/TypeScript, ale z jawnie zdefiniowanymi typami pól i konstruktorem o nazwie klasy.
